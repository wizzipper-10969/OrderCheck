สำหรับแอดมิน: อัปเดตข้อมูลจากไฟล์ Excel

อัปโหลดไฟล์ Excel รูปแบบเดียวกับไฟล์ต้นฉบับ (แต่ละชีตคือแต่ละวัน) ระบบจะอ่านข้อมูลและอัปเดตหน้านี้ทันที กดปุ่มด้านล่างเพื่อดาวน์โหลดไฟล์เว็บที่อัปเดตแล้ว แล้วอัปโหลดทับไฟล์ index.html เดิมใน GitHub เพื่อให้ทุกคนเห็นข้อมูลใหม่

หมายเลขโทรศัพท์และที่อยู่บางส่วนถูกซ่อนไว้เพื่อความเป็นส่วนตัว — กดปุ่ม "แสดงข้อมูลลูกค้าแบบเต็ม" เพื่อดูข้อมูลทั้งหมด
